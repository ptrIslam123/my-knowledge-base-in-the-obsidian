**Скользящее окно** — это техника, при которой мы работаем с подмножеством элементов массива/строки, которое «скользит» от начала к концу, обрабатывая по одному элементу за шаг. Вместо перебора всех возможных подмассивов (O(n²)), мы эффективно обновляем окно за O(1) или O(log n).

---

## **Ключевые компоненты паттерна**

1. **Указатели `left` и `right`** — границы окна.
2. **Текущее состояние окна** (сумма, хеш-таблица частот, и т.д.).
3. **Условие валидности** — когда окно «правильное».
4. **Логика расширения/сужения**.

## **Сложность**

- **Время:** O(n) — каждый элемент добавляется и удаляется из окна максимум один раз.
- **Память:** O(k) или O(1) в зависимости от того, что храним.

---
## **Когда использовать?**

| Ситуация | Пример задачи |
|----------|---------------|
| **Задачи на подмассивы/подстроки** | Найти подмассив с суммой = k |
| **Статистика в окне фиксированного размера** | Медиана/максимум в каждом окне размера k |
| **Поиск паттернов с условием** | Самая длинная подстрока без повторяющихся символов |
| **Оптимизация повторных вычислений** | Сумма каждого окна размера k |

## **Два основных типа**

### **1. Окно фиксированного размера**
Размер окна `k` не меняется.
```python
# Пример: сумма каждого окна размера k
def fixed_window(nums, k):
    window_sum = sum(nums[:k])  # Первое окно
    result = [window_sum]
    
    for i in range(k, len(nums)):
        window_sum += nums[i] - nums[i-k]  # Убираем левый, добавляем правый
        result.append(window_sum)
    return result
```

### **2. Окно переменного размера**
Размер окна меняется в зависимости от условия.
```python
# Пример: минимальная подстрока с суммой ≥ target
def variable_window(nums, target):
    left = 0
    curr_sum = 0
    min_len = float('inf')
    
    for right in range(len(nums)):
        curr_sum += nums[right]  # Расширяем окно справа
        
        while curr_sum >= target:  # Условие выполнено
            min_len = min(min_len, right - left + 1)
            curr_sum -= nums[left]  # Сужаем окно слева
            left += 1
    
    return min_len if min_len != float('inf') else 0
```



## **Задача: Максимальная сумма подмассива размера k**

**Дано:**
- Массив целых чисел `nums` длины `n`
- Целое число `k` (размер окна, `1 ≤ k ≤ n`)

**Найти:**
Максимальную сумму среди всех **подмассивов длины k** (непрерывных последовательностей из k элементов).

### **Примеры**

### **Пример 1:**
```
nums = [1, 4, 2, 10, 23, 3, 1, 0, 20]
k = 4

Подмассивы длины 4 и их суммы:
[1, 4, 2, 10] → сумма = 17
[4, 2, 10, 23] → сумма = 39  ← максимум!
[2, 10, 23, 3] → сумма = 38
[10, 23, 3, 1] → сумма = 37
[23, 3, 1, 0] → сумма = 27
[3, 1, 0, 20] → сумма = 24

Ответ: 39
```

### **Пример 2:**
```
nums = [100, 200, 300, 400]
k = 2

Подмассивы:
[100, 200] → 300
[200, 300] → 500
[300, 400] → 700  ← максимум!

Ответ: 700
```

### **Пример 3:**
```
nums = [-1, -2, -3, -4]
k = 2

Подмассивы:
[-1, -2] → -3
[-2, -3] → -5
[-3, -4] → -7

Ответ: -3  (наименее отрицательная сумма)
```

### **Решение: наивный подход vs скользящее окно**

### **1. Наивное решение (Brute Force)**
```python
def max_sum_naive(nums, k):
    max_sum = float('-inf')
    n = len(nums)
    
    for i in range(n - k + 1):  # O(n) стартовых позиций
        current_sum = 0
        for j in range(i, i + k):  # O(k) для каждой позиции
            current_sum += nums[j]
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```
**Сложность:** O(n × k)  
**Проблема:** При `n=10000`, `k=5000` → ~50 млн операций.

### **2. Оптимальное решение (Скользящее окно)**
```python
def max_sum_sliding_window(nums, k):
    # 1. Считаем сумму первого окна
    window_sum = sum(nums[:k])
    max_sum = window_sum
    
    # 2. Скользим окном
    for i in range(k, len(nums)):
        # Убираем элемент, выходящий слева
        # Добавляем элемент, входящий справа
        window_sum += nums[i] - nums[i - k]
        max_sum = max(max_sum, window_sum)
    
    return max_sum
```
**Сложность:** O(n)  
**Каждый шаг:** O(1) обновление суммы.

## **Задача: Найти длину самой длинной подстроки без повторяющихся символов**

**Дано:**
- Строка `s` (может быть пустой)

**Найти:**
Длину **самой длинной подстроки**, в которой **все символы уникальны** (не повторяются).

### **Пример 1:**
```
s = "abcabcbb"
Возможные подстроки без повторений:
- "abc" → длина 3
- "bca" → 3
- "cab" → 3
- и т.д.
Самая длинная: "abc" (или "bca", "cab") → длина 3

Ответ: 3
```

### **Пример 2:**
```
s = "bbbbb"
Все подстроки содержат только 'b', поэтому:
Самая длинная: "b" → длина 1

Ответ: 1
```

### **Пример 3:**
```
s = "pwwkew"
Подстроки без повторений:
- "pw" → 2
- "wke" → 3
- "kew" → 3
Самая длинная: "wke" или "kew" → длина 3

Ответ: 3
```

## ⚠️ **Что важно понимать**

- **Подстрока** — непрерывная последовательность символов.
- **Без повторений** — все символы в подстроке должны быть различны.
- Нужна **длина**, а не сама подстрока (хотя иногда просят и подстроку).

### **Оптимальное решение (Скользящее окно + хеш-таблица) — O(n)**
```cpp
int get_max_uniq_subseq(std::span<const char> arr) {
    std::unordered_set<char> seen;
    int left = 0, max_len = 0;

    for (int right = 0; right < static_cast<int>(arr.size()); ++right) {
        while (seen.contains(arr[right])) {
	        // при совпадении, значит уникальная последовательность закончиалась
	        // теперь будет искать следующу уникальную последователньость, но
	        // не с текущего right, а с left + 1, так как
	        // часть уникальных символов до дубликата всё ещё может
	        // быть использована
	        //
	        // Для этого удаляем крайний левый символ окна и стартуем
	        // следующее окно с left + 1
            seen.erase(arr[left]);
            ++left;
        }
        seen.insert(arr[right]);
        max_len = std::max(max_len, right - left + 1);
    }

    return max_len;
}
```

## **Maximum Window Substring

**Дано:**
- Строка `s` (длины `n`)
- Множество допустимых символов `allowed_chars`
- **Нет параметра `k`** (видимо, он не нужен для базовой версии)

**Найти:**
Максимальную (самую длинную) подстроку `s`, которая состоит **только из символов** `allowed_chars`.

**Пример:**
```
s = "aBC123de!@#fG456"
allowed_chars = {"a", "b", "c", "d", "e", "f", "g"}  # только буквы a-g
Результат: "de" (подстроки "aBC" и "fG" тоже valid, но "de" самая длинная? Надо проверить...)
```

## **Эффективное решение за O(n)**

### **Основная идея:**
Проходим по строке один раз, отслеживая текущую валидную подстроку. Когда встречаем недопустимый символ — начинаем новую подстроку.

```python
def max_allowed_substring(s, allowed_chars):
    """
    Находит самую длинную подстроку, состоящую ТОЛЬКО из allowed_chars.
    
    Возвращает (подстрока, начало_индекс, длина)
    """
    # Оптимизация: для быстрой проверки символов
    allowed_set = set(allowed_chars)
    
    max_start = 0
    max_len = 0
    current_start = 0
    current_len = 0
    
    for i, char in enumerate(s):
        if char in allowed_set:
            current_len += 1
            # Обновляем максимум, если текущая подстрока длиннее
            if current_len > max_len:
                max_len = current_len
                max_start = current_start
        else:
            # Невалидный символ — начинаем новую подстроку со следующего символа
            current_start = i + 1
            current_len = 0
    
    return s[max_start:max_start + max_len], max_start, max_len
```

## **Minimum Window Substring

**Дано:**
- Строка `s` (строка, в которой ищем)
- Строка `t` (шаблон, символы которого нужно найти)

**Найти:**
Минимальную (по длине) подстроку в `s`, которая содержит **все символы** из `t` (включая повторения).

Если такой подстроки нет, вернуть пустую строку `""`.

**Важно:** 
- Порядок символов в окне не важен.
- Должны быть все символы из `t` с нужными частотами.
- Подстрока должна быть непрерывной.

### **Пример 1:**
```
s = "ADOBECODEBANC"
t = "ABC"

Возможные подстроки, содержащие A, B, C:
- "ADOBEC" (длина 6) → содержит A, B, C
- "CODEBA" (длина 6) → содержит A, B, C
- "BANC" (длина 4) → содержит A, B, C ← минимальная!

Ответ: "BANC"
```

### **Пример 2:**
```
s = "a"
t = "aa"

Нужно найти две 'a', но в s только одна 'a'.

Ответ: ""
```

### **Пример 3:**
```
s = "a"
t = "a"

Ответ: "a"
```

### **Пример 4:**
```
s = "ab"
t = "b"

Ответ: "b"
```

## ⚠️ **Ключевые сложности**

1. **Учитывать частоты символов** — если в `t` две 'a', в окне должно быть минимум две 'a'.
2. **Символы в окне могут быть в любом порядке**.
3. **В окне могут быть лишние символы** (не из `t`).
4. **Нужно найти именно минимальное окно**.

## 🧠 **Интуиция решения**

Мы используем **два указателя** `left` и `right` и **счётчик недостающих символов**:

1. **Сначала расширяем `right`**, пока не соберём все символы из `t`.
2. **Потом сужаем `left`**, пытаясь уменьшить окно, но сохраняя все символы из `t`.
3. **Запоминаем минимальное окно**.
4. **Повторяем** до конца строки.

## 📈 **Пошаговый алгоритм**

### **Шаг 0: Подготовка**
```python
from collections import Counter

need = Counter(t)  # Частоты символов в t
missing = len(t)   # Сколько символов ещё нужно
```

### **Шаг 1: Основной цикл**
```python
def min_window(s, t):
    if not s or not t or len(s) < len(t):
        return ""
    
    need = Counter(t)
    missing = len(t)
    left = 0
    min_len = float('inf')
    min_start = 0
    
    for right, char in enumerate(s):
        # Если этот символ нужен (в t)
        if need[char] > 0:
            missing -= 1
        need[char] -= 1  # Уменьшаем потребность (может стать отрицательным)
        
        # Когда собрали все символы (missing == 0)
        while missing == 0:
            # Обновляем минимальное окно
            if right - left + 1 < min_len:
                min_len = right - left + 1
                min_start = left
            
            # Пытаемся сузить окно слева
            # Убираем left-символ из окна
            if need[s[left]] == 0:  # Если это был нужный символ
                missing += 1
            need[s[left]] += 1  # Восстанавливаем потребность
            left += 1
    
    return s[min_start:min_start + min_len] if min_len != float('inf') else ""
```

### **4. Подсчет анаграмм (LeetCode 438)**
```python
def find_anagrams(s, p):
    from collections import Counter
    p_count = Counter(p)
    s_count = Counter(s[:len(p)-1])
    result = []
    
    for i in range(len(p)-1, len(s)):
        # Добавляем правый символ
        s_count[s[i]] += 1
        
        # Проверяем на анаграмму
        if s_count == p_count:
            result.append(i - len(p) + 1)
        
        # Убираем левый символ
        s_count[s[i - len(p) + 1]] -= 1
        if s_count[s[i - len(p) + 1]] == 0:
            del s_count[s[i - len(p) + 1]]
    
    return result
```

### **5. Sliding Window Maximum (LeetCode 239) с deque**
```python
from collections import deque

def max_sliding_window(nums, k):
    dq = deque()  # хранит индексы
    result = []
    
    for i, num in enumerate(nums):
        # Удаляем элементы, выходящие из окна
        if dq and dq[0] == i - k:
            dq.popleft()
        
        # Удаляем элементы меньшие текущего
        while dq and nums[dq[-1]] < num:
            dq.pop()
        
        dq.append(i)
        
        # Когда окно сформировано
        if i >= k - 1:
            result.append(nums[dq[0]])
    
    return result
```

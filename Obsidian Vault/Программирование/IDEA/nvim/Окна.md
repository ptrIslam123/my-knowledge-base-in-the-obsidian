- **Окна (splits)** — это разделенные области экрана, в которых открыты файлы.
- **Плавающие окна (floating windows)** — это всплывающие окошки поверх всего (например, для ошибок).

---

## Управление окнами в Neovim

### Создание окон (сплитов)

| Команда                        | Что делает                                        |
| ------------------------------ | ------------------------------------------------- |
| `:split` или `Ctrl + w` → `s`  | Разделить окно **горизонтально** (сверху/снизу)   |
| `:vsplit` или `Ctrl + w` → `v` | Разделить окно **вертикально** (слева/справа)     |
| `:new`                         | Открыть новый пустой файл в горизонтальном сплите |
| `:vnew`                        | Открыть новый пустой файл в вертикальном сплите   |

### Навигация между окнами

| Команда          | Что делает                                 |
| ---------------- | ------------------------------------------ |
| `Ctrl + w` → `w` | Переключиться на следующее окно (по кругу) |
| `Ctrl + w` → `h` | Переключиться на окно **слева**            |
| `Ctrl + w` → `j` | Переключиться на окно **снизу**            |
| `Ctrl + w` → `k` | Переключиться на окно **сверху**           |
| `Ctrl + w` → `l` | Переключиться на окно **справа**           |

## Мапинги команд

### Как работают эти маппинги

Функция `vim.keymap.set()` имеет следующий синтаксис:

```lua
vim.keymap.set(mode, lhs, rhs, opts)
```

Где:
- **mode** — режим, в котором работает маппинг (`"n"` = normal mode)

- **lhs** — клавиша, которую ты нажимаешь (`"<C-h>"`)
   
- **rhs** — команда, которая выполняется (`"<C-w>h"`)

- **opts** — опции (например, `{ desc = "..." }` для описания)


```lua

-- 1) Shift + Tab - переключение на следующее окно (по кругу)
vim.keymap.set("n", "<S-Tab>", "<C-w>w", { desc = "Следующее окно" })

-- 2) Ctrl + n - создать новое вертикальное окно
vim.keymap.set("n", "<C-n>", ":vsplit<CR>", { desc = "Новое вертикальное окно" })

-- Shift + Q - переключиться на окно слева
vim.keymap.set("n", "<C-a>", "<C-w>h", { desc = "Окно слева" })

-- Shift + E - переключиться на окно справа
vim.keymap.set("n", "<C-d>", "<C-w>l", { desc = "Окно справа" }
```


### Закрытие окон

| Команда          | Что делает                           |
| ---------------- | ------------------------------------ |
| `:q` или `:quit` | Закрыть активное окно                |
| `:q!`            | Закрыть без сохранения               |
| `Ctrl + w` → `q` | Закрыть активное окно (альтернатива) |
| `:only`          | Закрыть все окна, кроме активного    |
| `Ctrl + w` → `o` | Тоже самое (`:only`)                 |

### Изменение размера окон

| Команда          | Что делает         |
| ---------------- | ------------------ |
| `Ctrl + w` → `+` | Увеличить высоту   |
| `Ctrl + w` → `-` | Уменьшить высоту   |
| `Ctrl + w` → `<` | Уменьшить ширину   |
| `Ctrl + w` → `>` | Увеличить ширину   |
| `Ctrl + w` → `=` | Выровнять все окна |

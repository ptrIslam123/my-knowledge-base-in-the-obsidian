Отличный вопрос! Навигация в Neovim — это одна из самых сильных сторон редактора. Всё делается с клавиатуры, без мыши. Разберу всё по порядку.

---

## 📍 1. Навигация по файлу

### Перемещение в начало/конец файла

| Команда | Что делает |
|---------|------------|
| `gg` | Перейти в **начало** файла (первая строка) |
| `G` | Перейти в **конец** файла (последняя строка) |
| `:0` или `:1` | Перейти на первую строку |
| `:$` | Перейти на последнюю строку |

**Пример:**
- Нажми `gg` — курсор в первой строке.
- Нажми `G` — курсор в последней строке.

---

### Переход по номеру строки

| Команда   | Что делает                                           |
| --------- | ---------------------------------------------------- |
| `:номер`  | Перейти на строку с указанным номером                |
| `номерG`  | Перейти на строку с указанным номером (альтернатива) |
| `номерgg` | Тоже самое                                           |

**Примеры:**
- `:42` + Enter — перейти на строку 42.
- `42G` — перейти на строку 42.
- `42gg` — перейти на строку 42.

---

### Прокрутка (скроллинг)

| Команда    | Что делает                                                    |
| ---------- | ------------------------------------------------------------- |
| `Ctrl + d` | Прокрутить **вниз** на пол-экрана (down)                      |
| `Ctrl + u` | Прокрутить **вверх** на пол-экрана (up)                       |
| `Ctrl + f` | Прокрутить **вниз** на целый экран (forward)                  |
| `Ctrl + b` | Прокрутить **вверх** на целый экран (backward)                |
| `Ctrl + e` | Прокрутить **вниз** на одну строку (экран остаётся на месте)  |
| `Ctrl + y` | Прокрутить **вверх** на одну строку (экран остаётся на месте) |

**Примеры:**
- `Ctrl + d` — быстро пролистать вниз на полэкрана.
- `Ctrl + u` — быстро пролистать вверх на полэкрана.
- `Ctrl + f` — пролистать вниз на целый экран.

---

### Перемещение по текущей строке

| Команда    | Что делает                                              |                                             |                     |
| ---------- | ------------------------------------------------------- | ------------------------------------------- | ------------------- |
| `0` (ноль) | Перейти в **самое начало** строки (самый левый символ)  |                                             |                     |
| `^`        | Перейти к **первому непробельному** символу в строке    |                                             |                     |
| `$`        | Перейти в **конец** строки (самый правый символ)        |                                             |                     |
| `g_`       | Перейти к **последнему непробельному** символу в строке |                                             |                     |
| `          | `                                                       | Перейти на указанный столбец (например, `42 | ` — на 42-й символ) |

**Примеры:**
- Нажми `0` — курсор в самом начале строки (позиция 0).
- Нажми `^` — курсор на первом символе, который не пробел (например, на букве).
- Нажми `$` — курсор в конце строки.

## 🔍 2. Навигация по словам и тексту

### Перемещение по словам

| Команда | Что делает                                                |
| ------- | --------------------------------------------------------- |
| `w`     | Перейти к **началу следующего** слова                     |
| `W`     | Перейти к началу следующего слова (игнорируя пунктуацию)  |
| `e`     | Перейти к **концу текущего** слова                        |
| `E`     | Перейти к концу текущего слова (игнорируя пунктуацию)     |
| `b`     | Перейти к **началу предыдущего** слова                    |
| `B`     | Перейти к началу предыдущего слова (игнорируя пунктуацию) |
| `ge`    | Перейти к **концу предыдущего** слова                     |

**Примеры:**
- `w w w` — прыгать по словам вперёд.
- `b b b` — прыгать по словам назад.

### Перемещение по предложениям и абзацам

| Команда     | Что делает                                           |
| ----------- | ---------------------------------------------------- |
| `(` или `)` | Перейти к началу/концу предложения                   |
| `{` или `}` | Перейти к началу/концу абзаца                        |
| `]]`        | Перейти к следующей секции (например, функция в C++) |
| `[[`        | Перейти к предыдущей секции                          |

---

## 🎯 3. Поиск внутри файла

| Команда  | Что делает                                |
| -------- | ----------------------------------------- |
| `/текст` | Искать **вперёд** по тексту               |
| `?текст` | Искать **назад** по тексту                |
| `n`      | Перейти к **следующему** совпадению       |
| `N`      | Перейти к **предыдущему** совпадению      |
| `*`      | Искать слово под курсором (вперёд)        |
| `#`      | Искать слово под курсором (назад)         |
| `:noh`   | Отключить подсветку поиска (no highlight) |

**Примеры:**
- `/main` + Enter — найти все `main`.
- `n` — перейти к следующему `main`.
- `*` — найти следующее вхождение слова под курсором.

## 📊 4. Сводная таблица (самое важное)

| Действие                    | Команда       |
| --------------------------- | ------------- |
| Начало файла                | `gg`          |
| Конец файла                 | `G`           |
| Строка N                    | `:N` или `NG` |
| Прокрутка вниз (полэкрана)  | `Ctrl + d`    |
| Прокрутка вверх (полэкрана) | `Ctrl + u`    |
| Прокрутка вниз (экран)      | `Ctrl + f`    |
| Прокрутка вверх (экран)     | `Ctrl + b`    |
| Начало строки               | `0` или `^`   |
| Конец строки                | `$`           |
| Следующее слово             | `w`           |
| Предыдущее слово            | `b`           |
| Поиск текста                | `/текст`      |
| Следующее совпадение        | `n`           |
| Предыдущее совпадение       | `N`           |

## 💡 Дополнительные советы

### Перемещение по видимой части экрана

| Команда | Что делает                                   |
| ------- | -------------------------------------------- |
| `H`     | Перейти к **верхней** строке экрана (High)   |
| `M`     | Перейти к **средней** строке экрана (Middle) |
| `L`     | Перейти к **нижней** строке экрана (Low)     |

### Быстрое перемещение по экрану с сохранением позиции курсора

| Команда | Что делает                              |
| ------- | --------------------------------------- |
| `zz`    | Центрировать экран по текущей строке    |
| `zt`    | Переместить текущую строку вверх экрана |
| `zb`    | Переместить текущую строку вниз экрана  |

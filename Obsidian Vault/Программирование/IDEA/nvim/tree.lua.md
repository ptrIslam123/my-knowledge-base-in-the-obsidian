
## Основы управления окнами в Neovim

Neovim (как и Vim) использует систему **сплитов** (разделенных окон). Каждый открытый файл или панель (как `NvimTree`) — это отдельное окно.

---

## Переключение между NvimTree и файлами

### 1. Базовый способ: `Ctrl + w` + `w`

Это **универсальная команда** для переключения между всеми открытыми окнами (сплитами). Нажимаешь `Ctrl + w`, потом отпускаешь и нажимаешь `w` — курсор перепрыгивает в следующее окно.

```
Ctrl + w  →  w  →  переключиться на следующее окно
Ctrl + w  →  W  →  переключиться на предыдущее окно (Shift + w)
```

**Как работает на практике:**
1. Ты в окне с кодом.
2. Нажимаешь `Ctrl + w`, потом `w` — курсор переходит в панель `NvimTree` (если она открыта).
3. Снова нажимаешь `Ctrl + w`, потом `w` — возвращаешься в файл.

### 2. Навигация по направлениям (быстрее)

Вместо того чтобы циклически переключаться, можно сразу указать, в какую сторону идти:

| Команда          | Что делает                       |
| ---------------- | -------------------------------- |
| `Ctrl + w` → `h` | Переключиться на окно **слева**  |
| `Ctrl + w` → `j` | Переключиться на окно **снизу**  |
| `Ctrl + w` → `k` | Переключиться на окно **сверху** |
| `Ctrl + w` → `l` | Переключиться на окно **справа** |

**Пример:** Если твоя панель `NvimTree` открыта слева, ты можешь переключаться между ней и файлом так:
- Из файла → в панель: `Ctrl + w` → `h` (влево)
- Из панели → в файл: `Ctrl + w` → `l` (вправо)

### 3. Закрыть NvimTree

| Команда            | Что делает                                     |
| ------------------ | ---------------------------------------------- |
| `:q` (или `:quit`) | Закрыть активное окно                          |
| `<leader>e`        | Закрыть/открыть NvimTree (у нас так настроено) |

Если ты находишься внутри `NvimTree`, можно просто нажать `q` — это закроет панель (так настроено по умолчанию).

## 🚀 Полезные команды для работы с окнами

### Открытие файлов в новых окнах

| Команда                        | Что делает                                        |
| ------------------------------ | ------------------------------------------------- |
| `:vsplit` или `Ctrl + w` → `v` | Разделить окно **вертикально**                    |
| `:split` или `Ctrl + w` → `s`  | Разделить окно **горизонтально**                  |
| `:new`                         | Открыть новый пустой файл в горизонтальном сплите |
| `:vnew`                        | Открыть новый пустой файл в вертикальном сплите   |

**Пример:** из файла нажимаешь `Ctrl + w` → `v` — экран разделится на две части, справа появится тот же файл (пустой буфер). Теперь ты можешь открыть там другой файл.

### Перемещение окон

| Команда          | Что делает                  |
| ---------------- | --------------------------- |
| `Ctrl + w` → `H` | Переместить окно **влево**  |
| `Ctrl + w` → `J` | Переместить окно **вниз**   |
| `Ctrl + w` → `K` | Переместить окно **вверх**  |
| `Ctrl + w` → `L` | Переместить окно **вправо** |

### Изменение размера окон

| Команда | Что делает |
|---------|------------|
| `Ctrl + w` → `+` | Увеличить высоту текущего окна |
| `Ctrl + w` → `-` | Уменьшить высоту текущего окна |
| `Ctrl + w` → `<` | Уменьшить ширину текущего окна |
| `Ctrl + w` → `>` | Увеличить ширину текущего окна |
| `Ctrl + w` → `=` | Выровнять все окна по размеру |

## 💡 Что ещё пригодится

### Для NvimTree (внутри панели)

Когда курсор находится внутри `NvimTree`:

| Клавиша | Что делает |
|---------|------------|
| `o` или `Enter` | Открыть файл/папку (в текущем окне) |
| `s` | Открыть файл в **горизонтальном** сплите |
| `v` | Открыть файл в **вертикальном** сплите |
| `i` | Показать/скрыть скрытые файлы (включить `dotfiles`) |
| `R` | Обновить дерево (refresh) |
| `a` | Создать новый файл |
| `d` | Удалить файл |
| `r` | Переименовать файл |
| `?` | Показать справку по клавишам |

### Полезные горячие клавиши для окон (дополнительно)

Если часто работаешь с несколькими окнами, добавь в `init.lua` эти маппинги для удобства:

```lua
-- Быстрое переключение между окнами
vim.keymap.set("n", "<C-h>", "<C-w>h", { desc = "Перейти в окно слева" })
vim.keymap.set("n", "<C-j>", "<C-w>j", { desc = "Перейти в окно снизу" })
vim.keymap.set("n", "<C-k>", "<C-w>k", { desc = "Перейти в окно сверху" })
vim.keymap.set("n", "<C-l>", "<C-w>l", { desc = "Перейти в окно справа" })
```

Теперь ты можешь переключаться между окнами, зажимая `Ctrl` и стрелки `h`, `j`, `k`, `l` — как в Tmux или IDE.

## 🎯 Итоговая таблица (самое важное)

| Действие | Команда |
|----------|---------|
| Переключиться на следующее окно | `Ctrl + w` → `w` |
| Переключиться на окно слева | `Ctrl + w` → `h` |
| Переключиться на окно справа | `Ctrl + w` → `l` |
| Переключиться на окно снизу | `Ctrl + w` → `j` |
| Переключиться на окно сверху | `Ctrl + w` → `k` |
| Закрыть активное окно | `:q` |
| Открыть/закрыть NvimTree | `<leader>e` (у нас пробел + e) |
| Вертикальный сплит | `Ctrl + w` → `v` |
| Горизонтальный сплит | `Ctrl + w` → `s` |

Теперь ты можешь быстро переключаться между панелью с деревом, кодом и другими окнами. Это один из самых мощных навыков в Neovim — управление окнами налету без мыши.

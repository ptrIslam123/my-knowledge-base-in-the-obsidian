
> "GROUP BY `Filed` соберет все уникальные значения `Field`, и каждое уникальное значение образует группу, куда попадут все записи с одинаковыми значениями `Field`"


### Синтаксис
```sql
SELECT [литералы, агрегатные_функции, поля_группировки]
FROM имя_таблицы
GROUP BY поля_группировки;
```


> Следует иметь в виду, что для GROUP BY все значения NULL трактуются как равные, т.е. при группировке по полю, содержащему NULL-значения, все такие строки попадут в одну группу

---

## Визуализация

**Исходные данные (все строки):**

| department | name    | salary |
|------------|---------|--------|
| Sales      | Alice   | 50000  |
| Sales      | Bob     | 60000  |
| IT         | Charlie | 70000  |
| IT         | Diana   | 80000  |
| HR         | Eve     | 45000  |

**Шаг 1: `GROUP BY department` находит УНИКАЛЬНЫЕ значения:**
- Уникальные department: `{'Sales', 'IT', 'HR'}`

**Шаг 2: Для каждого уникального значения создает ГРУППУ (множество):**

```
Группа "Sales" = {строка1 (Alice,50000), строка2 (Bob,60000)}
Группа "IT"    = {строка3 (Charlie,70000), строка4 (Diana,80000)}
Группа "HR"    = {строка5 (Eve,45000)}
```

**Шаг 3: SELECT применяется к КАЖДОЙ группе:**

```sql
SELECT department, AVG(salary)
FROM employees
GROUP BY department;
```

Результат:
- Для группы "Sales": department = 'Sales', AVG(salary) = 55000
- Для группы "IT":    department = 'IT',    AVG(salary) = 75000
- Для группы "HR":    department = 'HR',    AVG(salary) = 45000

Так, выполненный запрос сначала разбивает все записи из таблицы на 3 группы("Sales", "IT", "HR"), опираясь на поле `deparment`. Далее, для каждой группы суммирует все значения, взятые из поля `salary` у каждой записи, входящей в текущую группу, и затем полученный результат делится на количество записей в данной группе.

---

При использовании оператора GROUP BY мы перешли от работы с отдельными записями на работу с образовавшимися группами. В связи с этим мы не можем просто вывести любое поле из записи, как мы это могли делать раньше c обычным `SELECT`. Так как в каждой группе может быть несколько записей и в каждой из них в этом поле может быть разное значение.

При использовании GROUP BY мы можем выводить только:

* результаты агрегатных функций, т.е. вычисленные значения на основании набора значений. Напрмиер рассмотрим агрегатную функцию AVG.  Функция AVG принимает в качестве аргумента название поля, по которому мы хотим вычислить среднее значение для каждой группы.
```sql
    SELECT home_type, AVG(price) as avg_price FROM Rooms
    GROUP BY home_type
```

Так, выполненный запрос сначала разбивает все записи из таблицы `Rooms` на 3 группы, опираясь на поле `home_type`. Далее, для каждой группы суммирует все значения, взятые из поля price у каждой записи, входящей в текущую группу, и затем полученный результат делится на количество записей в данной группе.

- поля группировки. Мы можем их выводить, так как в рамках одной группы поля, по которым осуществлялась группировка, одинаковые.

## Групировка по двум или более полям

**При группировке по 2 и более полям принцип остается такой же, только теперь образовавшиеся группы дополнительно разбиваются на более мелкие группы в зависимости от второго поля группировки.**

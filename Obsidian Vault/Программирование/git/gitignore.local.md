Git есть прямой аналог локального `.gitignore`. Это файл **`.git/info/exclude`**, который хранится исключительно в вашем локальном репозитории и не передается другим пользователям.

### Как это работает

| Особенность | `.gitignore` | `.git/info/exclude` |
| :--- | :--- | :--- |
| **Где находится** | В корне репозитория (или в любой поддиректории) | Внутри папки `.git/info/` |
| **Версионируется Git** | Да, попадает в коммиты | Нет, только локально |
| **Для кого** | Для всех участников проекта | Только для вас |
| **Когда использовать** | Для общих файлов (артефакты сборки, зависимости) | Для личных файлов (заметки, конфиги IDE) |

### Как использовать

1.  **Откройте файл** `.git/info/exclude` в любом текстовом редакторе.
2.  **Добавьте правила** в том же формате, что и в `.gitignore`. Например, чтобы игнорировать ваш локальный файл `notes.md`, добавьте строку:
```text
    notes.md
```

3.  **Сохраните файл**. Git сразу начнет применять эти правила.

### Другие локальные варианты

Помимо `.git/info/exclude`, есть еще два способа для локального игнорирования:

*   **Глобальный файл игнорирования**: Вы можете настроить файл, который будет применяться ко **всем** вашим Git-репозиториям. Например, чтобы везде игнорировать файлы, создаваемые вашим текстовым редактором.

```bash
    # Установить глобальный файл (например, ~/.gitignore_global)
    git config --global core.excludesfile ~/.gitignore_global
```

*   **`git update-index`**: Специальные команды, чтобы временно игнорировать изменения в уже отслеживаемом файле. Например, вы хотите локально изменить конфигурационный файл, но не коммитить эти правки.
```bash
    # Игнорировать изменения в файле
    git update-index --skip-worktree <file>
    # Вернуть отслеживание
    git update-index --no-skip-worktree <file>
```

Этот метод предназначен для уже отслеживаемых файлов, в отличие от `.gitignore` и `exclude`, которые работают только с новыми, еще не отслеживаемыми файлами.

### Важное замечание

Как и обычный `.gitignore`, файл `.git/info/exclude` не повлияет на файлы, которые Git уже отслеживает. Если вы хотите игнорировать уже отслеживаемый файл, его нужно сначала перестать отслеживать командой `git rm --cached <file>`.

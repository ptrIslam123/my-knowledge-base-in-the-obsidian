### Шаг 0: Подготовка  
  
Обнуляем поле checksum в заголовке перед расчётом.  
  
```c  
ip->check = 0; // Важно! Иначе получим неверный результат  
```  
  
---  
  
### Шаг 1: Аккумуляция  
  
Складываем все 16-битные слова заголовка в 32-битный счётчик.  
  
**Почему 32 бита:** Чтобы сохранить переносы (carry) без потери данных.  
  
**Псевдокод:**  
```  
sum = 0  
для каждого 16-битного слова в заголовке:  
sum = sum + слово  
```  
  
**Пример:**  
```  
Слова: 0x4500, 0x003c, 0x1c46, 0x4000, 0x4006, 0x0000, 0xac10, 0x0a63, 0xac10, 0x0a0c  
  
sum = 0x4500 + 0x003c + 0x1c46 + 0x4000 + 0x4006 + 0x0000 + 0xac10 + 0x0a63 + 0xac10 + 0x0a0c  
sum = 0x00024e17 (32 бита, старшие 16 бит = 0x0002, младшие = 0x4e17)  
```  
  
---  
  
### Шаг 2: End-around carry  
  
**Что делаем:** Пока в старших 16 битах есть перенос — складываем старшие и младшие 16 бит.  
  
**Зачем:** Сворачиваем переносы обратно в сумму, пока результат не влезет в 16 бит.  
  
**Псевдокод:**  
```  
пока (sum >> 16) != 0: // пока старшие 16 бит не ноль  
старшие = sum >> 16 // выделяем биты 16-31  
младшие = sum & 0xFFFF // выделяем биты 0-15  
sum = старшие + младшие // складываем  
```  
  
**Пример:**  
```  
sum = 0x00024e17  
  
Итерация 1:  
старшие = 0x00024e17 >> 16 = 0x0002  
младшие = 0x00024e17 & 0xFFFF = 0x4e17  
sum = 0x0002 + 0x4e17 = 0x4e19  
  
проверка: 0x4e19 >> 16 = 0x0 → цикл окончен  
  
Результат: sum = 0x4e19 (≤ 0xFFFF, влезает в 16 бит)  
```  
  
---  
  
### Шаг 3: One's complement (инверсия)  
  
**Что делаем:** Инвертируем все биты результата (0→1, 1→0).  
  
**Зачем:** Чтобы при проверке сумма всех слов + checksum = 0xFFFF.  
  
**Псевдокод:**  
```  
checksum = ~sum // побитовая инверсия  
```  
  
**Пример:**  
```  
sum = 0x4e19 = 0100 1110 0001 1001  
~sum = 1011 0001 1110 0110 = 0xb1e6  
  
checksum = 0xb1e6  
```  
  
---  
  
### Шаг 4: Вставка в пакет  
  
```c  
ip->check = checksum; // 0xb1e6  
```  
  
---  
  
## Проверка корректности  
  
```  
Сумма всех слов заголовка (с checksum):  
0x4500 + 0x003c + 0x1c46 + 0x4000 + 0x4006 + 0xb1e6 + 0xac10 + 0x0a63 + 0xac10 + 0x0a0c  
= 0x2fffe  
  
End-around carry: 0x2fffe → 0xffff + 0x2 = 0x10001 → 0x0001 + 0x1 = 0xffff ✓  
  
Результат 0xFFFF = checksum корректен!  
```

## Код на C/C++  
  
### Чистый C  
  
```c  
#include <stdint.h>  
#include <arpa/inet.h> // для ntohs/htons  
  
// Расчёт checksum для произвольных данных  
uint16_t calculate_checksum(const uint16_t *data, int len) {  
	uint32_t sum = 0;
	  
	// Шаг 1: Аккумуляция 16-битных слов  
	while (len > 1) {  
		sum += *data++;  
		len -= 2;  
	}  
	  
	// Нечётный байт (если есть)  
	if (len == 1) {  
		sum += *(const uint8_t *)data;  
	}  
	  
	// Шаг 2: End-around carry  
	while (sum >> 16) {  
		sum = (sum & 0xFFFF) + (sum >> 16);  
	}  
	  
	// Шаг 3: One's complement (инверсия)  
	return ~sum;  
}  
  
uint16_t ip_checksum(struct iphdr *ip) {  
	int hdr_len = ip->ihl * 4; // длина заголовка в байтах  
	// Обнуляем checksum перед расчётом!  
	ip->check = 0;  
	return calculate_checksum((const uint16_t *)ip, hdr_len);  
}  
```

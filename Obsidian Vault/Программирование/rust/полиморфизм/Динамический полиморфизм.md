## **Trait Objects и vtable — архитектура**

[[Программирование/cpp/полиморфизм/Динамический полиморфизм|Динамический полиморфизм]] в с++ для сравнения

### **C++ vs Rust:**
| Аспект | C++ | Rust |
|--------|-----|------|
| **vptr расположение** | В начале объекта | В отдельном fat pointer |
| **Overhead на объект** | Всегда (8+ байт) | Только при использовании `dyn` |
| **Множественные интерфейсы** | Множественное наследование | Разные fat pointers |
| **Размер полиморфной ссылки** | 8 байт (указатель) | 16 байт (fat pointer) |

### **Структура fat pointer:**
```rust
// Box<dyn Trait> в памяти:
struct FatPointer {
    data: *mut (),     // 8 байт: указатель на данные в куче
    vtable: *mut (),   // 8 байт: указатель на vtable
}
```

Когда речь идет от статическом полиморфизме в rust, то box содердит просто указатель на начало памяти обьекта на куче. Но если полиморфизм динамический, тогда в box хранится не простой указатель, а толстый указатель: два указателя, первый на начало памяти обьекта на куче, а второй казатель на виртуальную таблицу обьекта(вместо того что бы размещать в начале самой структуры как это сделано в с++)  

### **Структура vtable в Rust:**
```rust
struct VTable {
    drop_in_place: fn(*mut ()),   // Деструктор
    size: usize,                  // Размер типа
    alignment: usize,             // Выравнивание
    method1: fn(*mut ()),        // Методы трейта...
    method2: fn(*mut (), arg: T),
}
```
